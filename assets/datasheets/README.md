# Product datasheets (local PDFs)

Drop OEM PDFs here, then register them in `app/js/product-datasheets.js`:

- `PRODUCT_DATASHEET_LOCAL_BY_ID` — catalog product id → file path
- `PRODUCT_DATASHEET_LOCAL_BY_NAME` — item-name regex → file path (when the stock row is a related SKU)

## Example (in the app)

**Canon imageRUNNER C3025i** — `canon-imagerunner-c3025i.pdf`

On List of Inventory, hover the printer (or C3025i waste toner) and click **Datasheet (PDF)**. That opens this file.

Source file used: `imageRUNNER C3025i datasheet.pdf` (Canon Europa, 2017).
