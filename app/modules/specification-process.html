Specs Evaluation

IT Dir ICT procurement specs run in three separate documents. Workshop prepares the ZNA (IT Dir Specification) and later the Spec Evaluation Form. Supplier Spec / Quotation is entered on the Supplier Window (Portals). After To Spec / Below Spec scoring, prices go to the Due Diligence Window (AIAD) for Cost Comparative and the certificate.

ZNA (IT Dir Specification)

Prepared by Workshop / Engineers when a requisition asks for ICT equipment (laptop, desktop, printer, server, tablet). Capture brand, RAM, storage, processor, and other key requirements. Cosigned by the preparer and OC Engineers, then attached to the DP F1 before calling suppliers.

Spec Evaluation Form

IT Dir compares each supplier’s offered specs against the ZNA (IT Dir Specification), ticking TO SPEC or BELOW SPEC per ITEM (as on the printed evaluation sheet). That decides the rightful supplier. Price scrutiny and the Due Diligence Certificate are done on the Due Diligence Window (AIAD portal) — Cost Comparative Schedule.

Open Technical Specs

Official SER / ITEM matrix with supplier columns (BELOW SPEC / TO SPEC). Stays a separate button for now — shares ZNA ITEMs and supplier quotes with this process.
