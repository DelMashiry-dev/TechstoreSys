IT-DIR Tech Stores — Phone installation guide

This system runs on the Tech Stores PC. Keep START-SYSTEM.bat running on that PC while you use the phone.

1) On the PC
   - Double-click START-SYSTEM.bat
   - Leave that window open
   - Note the "Phone (same Wi-Fi)" address printed there
     Example: http://192.168.x.x:8080/app/

2) On your phone
   - Connect to the SAME Wi-Fi as the PC
   - Open Chrome (Android) or Safari (iPhone)
   - Type the Phone address from the PC window (use /app/ at the end)

3) Add to Home Screen / Install
   Android (Chrome):
     Menu ⋮ → Add to Home screen  (or Install app)
   iPhone (Safari):
     Share → Add to Home Screen

4) Login (examples)
   admin / admin123
   store / store123
   viewer / view123

Notes
- The PC server must stay on for the phone to connect.
- If the page will not load, check Wi-Fi, firewall, and that you used the PC LAN IP (not 127.0.0.1).
- 127.0.0.1 only works on the PC itself.
