Money path (buying power)

  1. DAF issues monthly target / vote per GL.
  2. System tracks committed (bids, POs, DP F1) and expended.
  3. Buying power = Target − Expended. Buys blocked if insufficient.
  4. Release Cut moves buying power between GLs for that month.

Dashboard GL Target Overview is the live control board for this path.

Stock path (stores)

  1. Delivery note / receive posts on hand.
  2. Issue voucher / unit requisition posts issues.
  3. Stock Take lists Consumables, ICT, Spares, Softwares — physical vs system.
  4. Variance can push to ZNA Q 987 stocktaking certificate.

Stock ledgers are inventory families — not the same as GL budget cards.
